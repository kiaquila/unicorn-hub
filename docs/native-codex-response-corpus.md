# Native Codex response corpus

The regression corpus covers every clean closing observed across the maintained repositories, complete native help footers, receipt markers, commit proof and task links. Source identities and task IDs are synthetic in fixtures.

Every accepted response is paired with negative tests for added security findings, foreign commit proof, duplicate proof, forged help text and reviewer impersonation. Existing structured state, request authority, completion clocks and unresolved-thread gates remain authoritative. Unknown service output stays blocked until a reviewed fixture establishes its meaning.

Local verification uses the repository preflight and Node regression suite. Delivery verification requires an owner request `@codex review <full current HEAD>`, native clean evidence, all checks green, resolved threads and at least 120 seconds without changing that evidence before ordinary protected merge.
